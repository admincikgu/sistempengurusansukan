# SMKDHAB PWA

The site can be installed as an app on supported browsers.

- Web App Manifest
- Service worker
- Install App button
- Offline app-shell fallback
- Static asset caching
- Live API/database requests are never cached

Deploy to Vercel over HTTPS. On Chrome/Edge/Android use the Install App button or browser install option. On iPhone/iPad Safari use Share → Add to Home Screen.
